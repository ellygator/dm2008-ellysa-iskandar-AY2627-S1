### The Project

<!-- What does your sketch do, and what physical input drives it?
     How does the sensor data translate into something on screen?
     A few sentences is all you need. -->

     This week, I connected an Arduino sensor to p5.js to control heart-shaped visuals on screen. The visuals changed between a row of small outlined hearts and a large pink heart with expanding outlines in response to the sensor input. Z and I customised the colours and shapes to make the interaction more playful. This helped me understand how sensor data can turn a physical action into a visual response on screen.
